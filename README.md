# S&P 500 Portfolio Analysis - Clustering and Business Intelligence insights

## Project Overview

Analysis of historical S&P 500 market data to identify price trends, returns, volatility, and significant market movements, to transform financial data into actionable business insights.

## Project Objectives

* Collect and prepare historical S&P 500 data.
* Analyse prices, returns, trends, and volatility.
* Identify significant market movements and patterns.
* Visualise key findings effectively.
* Generate actionable financial insights.

## Project Workflow

```text
Data Collection
      ↓
Data Cleaning & Preparation
      ↓
Exploratory Data Analysis
      ↓
Feature Engineering
      ↓
Trend & Volatility Analysis
      ↓
Data Visualisation
      ↓
Insights & Recommendations
```

## Solution Overview

The project delivers an end-to-end financial data analytics solution that transforms historical S&P 500 data into meaningful insights through data cleaning, statistical analysis, feature engineering, and visualisation.
